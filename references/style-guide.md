## 共同视觉语法

### 轮廓与形体

- 先设计可辨认的整体剪影，再用内部色块说明结构。
- 发型、衣袖、裙摆和配件概括为大形状，直线、尖角与饱满弧线形成节奏。
- 头部相对偏大，五官集中；躯干和四肢可适当拉长，不固定为一种头身比。
- 姿态可以正面、侧身、回望或坐姿；轻微倾斜和不对称可增加角色个性。
- 以相邻色块的边界塑形，整体基本不加统一黑色外描边。
- 眼睑、眉毛、嘴、耳朵和衣物转折可以保留少量深色或同色系内线。

### 面部与表情

- 眼睛具有明确形状和方向，不默认画成实心豆豆眼。
- 用较重的上眼睑、可见眼白、简化虹膜或高光表达注视方向。
- 半垂眼、斜视、锐利眼角或圆润大眼都可使用，由角色性格决定。
- 眉眼关系承担主要情绪；冷淡、拽感、困倦、俏皮和愉快均可成立。
- 鼻子与嘴巴小而概括，避免写实鼻梁和密集面部刻画。
- 腮红、耳内色和脸颊阴影可采用圆形或简洁异形块，不强制每个角色都带腮红。
- 星形瞳孔、夸张睫毛等属于可选表达，不作为每张图的固定标识。

### 光影与表面

- 保持平面感，用少量明暗色块说明脸、头发和衣物的转折。
- 阴影以简洁硬边为主，不追求连续写实塑形、强烈体积光或复杂反射。
- 可在皮肤、浅发或局部气氛中使用很轻的渐变，边缘和大形仍应清楚。
- 纸感颗粒是可选的轻度处理，不能掩盖轮廓，也不必为了统一而强行添加。
- 成品可以有矢量感，但交付仍是 ImageGen 生成的位图插画。

## 四项输入如何进入画面

| 输入 | 对画面的作用 |
| --- | --- |
| 主题 | 决定情境、情绪、姿态，以及是否需要一个主要道具或少量场景装饰 |
| 人物造型 | 决定身份、年龄、性别表达、发型、服装、配件及体态，不继承参考人物身份 |
| 主要颜色及用途 | 明确主色具体用于背景、服装、头发或其他主体区域 |
| 次要颜色及用途 | 明确辅色用于与主色形成关系的服装、配件、装饰或其他指定区域 |

- 用户指定的颜色用途应在画面中清楚可见，不只把颜色作为零散点缀。
- 两项配色输入是颜色分工，不意味着整幅画只能使用两种颜色。
- 可按需要加入肤色、米白、近黑和少量必要点睛色，以及少量同色系明暗变体。
- 保持有限且有主次的配色，避免无依据地增加多种高饱和竞争色。
- 不把参考中常见的红、粉、蓝背景固定为必选，也不擅自把指定衣服颜色移到背景。
- 不为迁就配色而改变角色身份；特殊肤色或非人角色形态应来自本次设定。

## 构图与可变内容

- 角色是视觉中心；头像突出眉眼和发型，半身强调手势或道具，全身保留完整姿态。
- 纯色背景是常用起点；主题需要时，可加入少量平面装饰或简化场景。
- 装饰应服务于人物剪影和主题，不复制风格参考的整套烟雾、图案或道具组合。
- 允许人物身份、年龄、性别、发色、服装、表情和姿势自由变化。
- 动物、植物、怪物、机械元素及幻想配件可由主题引入，不限定猫耳、角或日式服装。
- 配件和花纹的复杂度随题材调整，但不能让小细节取代主要色块。
- 默认是一幅无文字插画；不自动增加海报排版、签名、边框或水印。
- 画幅与裁切服务于本次构图，不机械沿用参考图的尺寸和位置。

## 紧凑提示词骨架

将占位内容替换为本次设定，删去不适用的可选项；不要把风格参考的角色描述填成默认人物。用户明确要求文字、保留角色或修改已有图片时，相应调整“无文字”“创作新角色”等默认表述，并列明输入图片的角色。

```text

人物造型：{身份与外观、发型、服装、配件}。
主要颜色：{颜色}，用于{明确区域或对象}。
次要颜色：{颜色}，用于{明确区域或对象}。

输入图片：{每张图的编号、风格参考／造型参考／待修改图角色及保留范围}。
风格参考仅提供画法：大色块塑形，鲜明人物剪影，夸张发型与适度大头比例，
色块边界清晰，基本无统一外描边，只保留少量面部和结构内线。
眼睛富有表情，有明确上眼睑与注视方向；鼻嘴简化，不使用默认豆豆眼。
以有限主色和简洁平面阴影保持画面统一，允许必要肤色、浅色、深色和少量点睛色。
{可选：局部轻微渐变／轻纸纹／围绕人物的少量平面装饰}。
除用户明确指定保留的角色与内容外，创作新的角色与组合，不自动沿用风格参考人物身份、具体服装道具整套搭配，
不生成参考中的文字、署名、水印、平台标记或拼版。
```

## 判断是否抓住风格

- 缩小观看时，人物、发型和姿态仍能从大色块中辨认。
- 眼神与眉形表达了设定的情绪，五官保持简洁。
- 主色和辅色落在指定用途上，其他颜色支持画面而不争夺重点。
- 保留平面插画感；轻微纹理或过渡没有变成写实渲染。
- 人物内容来自本次输入，参考中未经要求的文字和独特角色搭配没有被带入。
